Gold Bank installed as release "{{ .Release.Name }}" in namespace "{{ .Release.Namespace }}".

Check the pods:
  kubectl get pods -n {{ .Release.Namespace }}

Open the app:
{{- if .Values.ingress.enabled }}
  Ingress host: http://{{ .Values.ingress.host }}  (add it to your hosts file, `minikube ip`)
{{- else if eq .Values.service.type "NodePort" }}
  minikube service {{ include "gold-bank.fullname" . }} -n {{ .Release.Namespace }}
{{- else }}
  kubectl port-forward svc/{{ include "gold-bank.fullname" . }} 8080:{{ .Values.service.port }} -n {{ .Release.Namespace }}
  then open http://localhost:8080
{{- end }}

Login password: the value of secret.APP_PASSWORD.
